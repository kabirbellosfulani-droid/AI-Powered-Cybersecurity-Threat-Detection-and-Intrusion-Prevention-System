Copy-paste examples

# health check
curl http://127.0.0.1:5000/api/health

# run a 2000-flow exercise at 20% attack rate
curl -X POST http://127.0.0.1:5000/api/simulate \
  -H "Content-Type: application/json" \
  -d '{"n_events": 2000, "attack_rate": 0.20, "seed": 42}'

# score an SSH brute-force flow by hand
curl -X POST http://127.0.0.1:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{"service":"ssh","num_failed_logins":6,
       "logged_in":0,"src_bytes":120,"dst_bytes":60,
       "count":20,"srv_count":20,"flag":"S0"}'

How to extend this project (interview ammunition)

Real traffic

Swap TrafficSimulator for Scapy capture (sniff(prn=handler)), a Zeek/Suricata eve.json tail, or pyshark. The detection layer needs zero changes — it already accepts any DataFrame with the 41 NSL-KDD fields downstream of feature engineering.

SIEM integration

Ship alerts to Elastic/OpenSearch (ECS format), Splunk HEC or Wazuh. Add a /api/alerts webhook consumer and map our fields to ECS: source.ip, event.severity, threat.technique.id.

Modelling upgrades

Try XGBoost/LightGBM, an autoencoder for reconstruction-error anomaly detection, or LSTM over flow sequences (time-aware). Compare with the baseline table on the Model Intelligence page and keep the winner.
